# Mis Hábitos — Calendario

App en React (Vite) para marcar cada día: **Vitalidad**, **Medicamento** y **Ejercicio/Creatina** (Sí / No).

- Datos guardados en `localStorage` (clave `habitos:data`).
- Estadísticas por semana, mes y año (Recharts).
- Exportar a Excel (.xlsx) y compartir por WhatsApp.
- Tema claro por defecto y modo oscuro.

## Uso

```bash
npm install
npm run dev
```

Para producción: `npm run build` (genera `dist/`, se puede abrir en cualquier hosting estático).
